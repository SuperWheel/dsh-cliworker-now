# native-output-budget Specification

## Purpose
让大输出的工具调用不再导致 Worker 整轮被终止：插件传输层不重复放大工具输出，超出展示预算只截断展示，预算按字节统一计算并读取同一配置，并如实说明 CLI 自身对模型可见输出的上限。

## Requirements

### Requirement: 工具输出传输不重复放大
原生 runner SHALL 对运行中的工具输出只传输新增部分，同一工具的完整输出在完成时 MUST 至多传输一份；原生原始记录 MUST NOT 再重复携带同一份大正文。公开思考 SHALL 以增量或有界快照传输。传输总量 SHALL 与 CLI 实际输出量呈线性关系。

#### Scenario: 读取较大文件
- **WHEN** CLI 一条命令输出 400KB，分为多段增量
- **THEN** 插件传输量约为该输出的常数倍，整轮继续运行，界面按同一工具步骤聚合显示

#### Scenario: 长任务多次读文件
- **WHEN** 一轮任务连续执行 50 条各输出 64KB 的命令
- **THEN** 不因插件传输累计量终止运行

### Requirement: 展示预算超限只截断展示
工具输出、思考或原始记录超过展示预算时，插件 SHALL 截断展示内容并明确标注已截断及完整内容的去处，MUST NOT 因展示数据超限终止 CLI 进程或改变本轮终态。原生入站单个协议帧超过入站保护上限时 SHALL 停止并报告具体原因，该上限与展示预算分别配置。

#### Scenario: 单个工具输出超过展示预算
- **WHEN** 一个工具输出超过单工具展示预算
- **THEN** 时间线显示有界预览与截断标记，CLI 继续运行，终态不受影响

#### Scenario: 入站协议帧过大
- **WHEN** CLI 单行协议帧超过入站保护上限
- **THEN** 运行停止，错误说明入站帧过大及当前上限，不报告为成功

### Requirement: 预算按字节计算并统一读取配置
各层大小检查 SHALL 按 UTF-8 字节计算并为包装预留余量；Pi/OMP 等独立桥 SHALL 使用 Host 配置的预算，MUST NOT 使用另行写死的数值。

#### Scenario: 多字节工具结果
- **WHEN** 工具桥返回接近上限的中文结果
- **THEN** 各层判定一致，不出现上层通过、下层因字节超限失败

### Requirement: 说明 CLI 模型可见输出预算
文档 SHALL 区分插件传输预算与 CLI 自身的模型可见输出预算，写明 Codex 模型可见输出由其原生配置与模型每次调用参数决定、插件不覆盖。插件 MUST NOT 声称调整自身预算能扩大模型可见输出。

#### Scenario: 用户调大插件预算后模型仍看到截断
- **WHEN** 用户调大 `maxRunBytes` 后 Codex 模型读取的文件内容仍被截断
- **THEN** 文档指明该截断来自 Codex 原生输出预算及对应原生配置位置
