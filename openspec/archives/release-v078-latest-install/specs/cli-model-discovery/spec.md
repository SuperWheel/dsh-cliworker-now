## ADDED Requirements

### Requirement: 设置模型目录持久保存与启动刷新
Host SHALL 按机器、平台、项目和 CLI 保存已核验的可选模型及其思考强度，缓存只用于设置选项展示，不得替代保存选型或任务启动时的原生账号/路由核验。每次宿主启动后首次打开对应设置页 MUST 重新识别目录；本轮后续打开可复用同来源目录。目录相同不得重写缓存，变化时更新；有效的项目默认值保持不变，无效默认值要求重新选择。

#### Scenario: 重复打开与宿主重启
- **WHEN** 同一宿主中再次打开已完成识别的 CLI 设置页
- **THEN** 自动填入已核验的模型及强度列表；宿主重启后首次打开重新识别，并仅在内容变化时更新持久文件

#### Scenario: 账号或路径变化
- **WHEN** 当前账号、路由、CLI 路径改变或用户主动刷新
- **THEN** 旧目录不能继续作为新来源的选项，重新识别失败时显示错误，不回退旧目录掩盖失败

#### Scenario: 已选偏好
- **WHEN** 重新识别得到的列表仍支持已选默认模型及强度
- **THEN** 保留该默认值；失效时显示需要重新选择，目录刷新本身不保存猜测的替代模型或启动任务

#### Scenario: 查询取消与并发
- **WHEN** 多个设置请求同时到达或请求被取消
- **THEN** 同来源查询串行复用，取消结果不得写入缓存；Host 退出时清理正在执行的查询

#### Scenario: 缓存目录或祖先路径是链接
- **WHEN** 设置模型缓存目录、状态根或其非可信祖先路径是符号链接或 Windows junction
- **THEN** 在创建或写入缓存前拒绝，不在链接目标中创建目录或文件，不改变目标内容与权限，不从不安全路径恢复选项

### Requirement: Codex 当前账号模型与客户端版本
Codex 目录查询 SHALL 使用当前已解析 CLI 的原生握手版本，不能把本 CLI 查询固定到旧版本。当前账号远端目录已确认的模型和 reasoning 能力 SHALL 能更新原生 bundled/cache 的陈旧清单；模型 ID 与强度 MUST 取真实元数据，不得按模型名称推测或硬编码补项。额度、认证与账号来源仍须当前核验。

#### Scenario: 原生缓存缺少最新模型
- **WHEN** 当前账号目录确认某模型及 reasoning 能力，但 app-server 模型清单仍使用旧 bundled/cache
- **THEN** 按该账号当前确切 ID 与强度显示选项，不因旧缓存缺项而删除，不补入没有能力元数据的未知模型

#### Scenario: 实际客户端版本
- **WHEN** 原生 initialize 握手报告当前 CLI 版本
- **THEN** 本次远端目录请求使用该版本，不发送旧固定版本或猜测的 latest

#### Scenario: 账号拒绝或额度不足
- **WHEN** 当前账号认证失败、范围未知或额度已耗尽
- **THEN** 不使用原生或旧缓存清单掩盖失败，不显示未经支持确认的选项

#### Scenario: 模型介绍提示不是权限拒绝
- **WHEN** 当前账号模型具有支持证据和真实 reasoning 元数据，并附带介绍性的 availability_nux 提示
- **THEN** 不因介绍提示本身隐藏该模型；明确拒绝、未获支持或隐藏条目仍按当前账号与原生能力规则排除

## MODIFIED Requirements

### Requirement: Claude 自身网关配置模型
Claude 的当前自身网关若不提供模型目录，或当前自身 loopback 代理成功返回原始空目录但仍有明确角色映射，Host SHALL 仅将该路由中明确配置的有效模型作为候选，标注来自路由配置且远端可用性未核验、费用未知。原生上下文后缀 SHALL 保留在选型和执行中，目录求交仅移除原生支持的后缀。明确认证拒绝、网络失败或无效响应 MUST 不通过配置候选或官方账号回退掩盖。

#### Scenario: 网关目录未实现
- **WHEN** Claude 自身 API 或本地网关的目录返回 404/405，且当前自身 settings 明确配置了模型
- **THEN** 仅显示这些配置模型及证据说明，不将其描述为账号权益、免费模型或真实生成成功，不补入官方或公共模型

#### Scenario: 目录确认且模型带上下文后缀
- **WHEN** 当前路由确认 glm-example，而自身配置模型为 glm-example[1M]
- **THEN** 保留该原生配置标识作为选项和 argv，比较目录时按 Claude 原生后缀规则匹配，其他任意后缀不推测

#### Scenario: 目录认证拒绝或查询异常
- **WHEN** 网关返回 401/403、网络失败或无效目录响应
- **THEN** 返回简短失败原因，不开放配置候选、不切换官方账号，取消仍结束请求

#### Scenario: 选型期间切换网关映射
- **WHEN** CC Switch 在选型、排队或续聊时改变当前路由模型映射
- **THEN** 当前选择及绑定重检并失效，需要重新选择或新建任务，不能使用旧映射覆盖新配置

#### Scenario: 本地代理辅助目录成功为空
- **WHEN** 当前自身 loopback Claude 代理返回成功的原始空模型数组，且自身原生 settings 明确配置有效角色模型
- **THEN** 保留确切角色模型 ID 和原生上下文后缀，显示路由配置、远端未核验及费用未知；MODEL_NAME 仅作为标签，不成为执行 ID

#### Scenario: 权限过滤后为空或远端目录成功为空
- **WHEN** 实际目录含拒绝项而筛选后为空，或非 loopback 远端网关成功返回空目录
- **THEN** 不恢复配置候选，不把空目录等同于未实现；认证拒绝、失败和无效响应仍按既有拒绝行为处理
