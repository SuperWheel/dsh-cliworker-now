# Design

## Context
2026-11-15 用户在 Mac 与 Windows Desktop 报告账号终端偶发启动失败、登录后列表不刷新、Pi 无法退出与打开账号窗口、自建配置无法删除、账号行换行。

## Decisions

### 决定 1：账号终端与读取通道串行
账号终端与同一 CLI 的账号查询、模型目录读取共用进程边界。终端启动前等待旧读取的进程范围退出，终端占用期间拦截新读取；不靠加大超时。

### 决定 2：成功状态在清理之后发布
登录基线在终端启动前读取；成功按钮与关闭回执在进程清理、目录释放、缓存作废之后发布，窗口随后直接做带句柄的新读取。

### 决定 3：原生配置文件中的服务商允许删除（用户决定，2026-11-15）
`api.po1nt9.me` 实际位于用户 `~/.omp/agent/models.yml`（2026-08-04 写入），插件只是快照复制。用户选择「允许删除，同时改原生文件」。删除前备份到 `<stateDirectory>/account-config-backups/`，YAML 按节点位置编辑，不重新序列化；环境变量来源仍只读。

### 决定 4：多凭据账号摘要同排截断
多凭据摘要与「账号」「账号终端」按钮同排，摘要以「…」截断并悬停显示全文（`doc/settings-ui-design.md`）。
