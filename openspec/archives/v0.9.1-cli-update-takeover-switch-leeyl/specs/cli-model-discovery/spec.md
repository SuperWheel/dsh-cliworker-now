## MODIFIED Requirements

### Requirement: 设置模型目录持久保存与启动刷新
Host SHALL 按机器、平台、来源范围和 CLI 保存已核验的可选模型及其思考强度：设置页的来源范围是整机（不含项目，主对话没有目录或目录已不存在时照常读取和展示），派遣与 Worker 对话的来源范围是其项目。缓存只用于选项展示，不得替代设置页保存选型或任务启动时的原生账号/路由核验；Worker 改选按专门规则允许保存缓存内偏好并延后实际核验。每次宿主启动后首次打开对应设置页 MUST 重新识别目录；本轮后续打开可复用同来源目录。目录相同不得重写缓存，变化时更新；有效的项目默认值保持不变，无效默认值要求重新选择。

#### Scenario: 重复打开与宿主重启
- **WHEN** 同一宿主中再次打开已完成识别的 CLI 设置页
- **THEN** 自动填入已核验的模型及强度列表；宿主重启后首次打开重新识别，并仅在内容变化时更新持久文件

#### Scenario: 账号或路径变化
- **WHEN** 当前账号、路由、CLI 路径改变或用户主动刷新
- **THEN** 旧目录不能继续作为新来源的选项，重新识别失败时显示错误，不回退旧目录掩盖失败

#### Scenario: 已选偏好
- **WHEN** 重新识别得到的列表仍支持已选默认模型及强度
- **THEN** 保留该默认值；失效时显示需要重新选择，目录刷新本身不保存猜测的替代模型或启动任务

#### Scenario: 查询取消与并发
- **WHEN** 多个设置请求同时到达或请求被取消
- **THEN** 同来源查询串行复用，取消结果不得写入缓存；Host 退出时清理正在执行的查询

#### Scenario: 缓存目录或祖先路径是链接
- **WHEN** 设置模型缓存目录、状态根或其非可信祖先路径是符号链接或 Windows junction
- **THEN** 在创建或写入缓存前拒绝，不在链接目标中创建目录或文件，不改变目标内容与权限，不从不安全路径恢复选项

#### Scenario: 设置页不随项目变化
- **WHEN** 先后在两个不同项目的主对话，或没有目录的主对话里打开同一 CLI 的设置页
- **THEN** 显示同一份整机模型清单，不重复识别；项目默认值只在主对话有可用项目时带出
