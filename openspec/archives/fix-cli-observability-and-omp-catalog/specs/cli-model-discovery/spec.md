# Spec Delta

## ADDED Requirements

### Requirement: OMP 订阅目录与原生执行同步
OMP 的 OpenAI 订阅模型 SHALL 根据当前自身账号支持范围和原生能力元数据更新旧目录缺项；模型 ID、容量和推理能力 MUST 有原生来源，不能硬编码新型号或只在菜单增加无法执行的模型。查询和执行使用相同来源，保留已有有效偏好，不改变账号权限或用户原生目录文件。

#### Scenario: 账号目录有新模型
- **WHEN** 当前 OMP 订阅账号确认新模型及完整可执行能力，但旧原生缓存缺项
- **THEN** 目录显示精确模型和支持强度，原生执行器通过同一受管目录可解析该模型；不替用户自动选择。

#### Scenario: 账号池或能力不完整
- **WHEN** 任一可能执行账号未支持模型、查询失败或元数据不足以确认原生执行能力
- **THEN** 不扩大候选，不静默使用另一个账号、旧缓存或猜测参数。

#### Scenario: 取消与原生状态保护
- **WHEN** 用户取消目录刷新或原生元数据失败
- **THEN** 结束本次查询并清理临时状态，不改写用户原生账号、会话和模型缓存；必要的同账号凭据正常轮换遵循既有保存规则，不启动模型生成。
