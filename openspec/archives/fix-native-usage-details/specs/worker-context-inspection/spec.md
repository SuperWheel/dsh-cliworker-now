## MODIFIED Requirements

### Requirement: 原生上下文菜单和分项边界
上下文查看 SHALL 对齐 Harness 0.2.0-rc.2 原生菜单的触发、布局、字体、圆环、总量和分段条，并支持系统提示词、工具定义、对话消息等有证据的分类。未知分项 MUST 使用 `—` 明确为未提供，不以字符比例或父会话数据编造 token，不将未知当零，不为填满原生样式伪造分段。全部 CLI 的弹层 SHALL 删除重复缺失说明，保留估算标记，并在最后一项后只保留正常内边距。

#### Scenario: 有完整原生分项
- **WHEN** CLI 提供当前窗口总量、容量和可核查的提示词/工具/对话分类
- **THEN** 按原生菜单呈现相应分项与占比，分类和总量口径一致，估算值有明确标记

#### Scenario: 只有总量
- **WHEN** CLI 仅提供总占用与容量，缺少系统提示词或工具定义等分类
- **THEN** 原生菜单展示总量和未知分项，不附加“当前记录缺少部分分类统计”等段落，不宣称取得完整内部上下文或分类。
