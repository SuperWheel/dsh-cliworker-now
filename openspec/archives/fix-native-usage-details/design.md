# Design

## Context

`harness-turn-usage.ts` 只投影 Token，Qoder 的积分仍停留在输入框底部。`TurnUsagePanel` 使用原生包装调用的内部模型路由；`ContextMeter` 的说明段落增加空白。

## Goals / Non-Goals

覆盖原生回复用量、上下文弹层与插件回退组件。保留实际数据、未知和估算边界；不新增计费请求，不更改原生 Session 事件、模型执行身份、凭据或版本。

## Decisions

1. 扩展现有逐轮投影，积分、原生数值回退及展示路由使用显式字段。按去重后的已结算 run 汇总积分；任一成员未知时整轮积分未知，不能借用当前轮数据填充历史。
2. 展示路由只从对应 run 的 `observedModel` 事件取得，Hermes 原生 provider/model 对及明确 provider/model ID 保留原值；提供方缺失显示“未公开”。模型元数据独立于账单，缺少总账单时可保留原生精确回复计数并覆盖展示名称。
3. 全部统计弹层取消重复说明段落，未知保留 `—`，正常上下文分项不附加缺失分类提示；不隐藏真实请求错误。
4. Windows 使用现有历史和隔离模拟测试验收，再在无活动任务时通过官方插件入口安装隔离候选包；保留已有会话及账号数据。

## Risks / Trade-offs

旧历史没有可确认模型或 turn/run 绑定时不能猜测名称或积分。提供方别名沿用真实来源，不能把示例名称替换为并不存在的提供方。断连清除数字，已知积分计费单位仍保留。

## Migration Plan

契约为可选增量，不改写存储。失败时可回退安装前插件备份；只清理本次任务与测试目录。
