## ADDED Requirements

### Requirement: 显式的只读浏览器原语检查
开发工具 SHALL 接受显式指定的宿主前端目录及可选插件候选根目录，在验证 runtime 清单后，解析而不执行 JavaScript，比对四个替代界面引用的具名原语与宿主实际注入导出。不读取或修改用户会话、凭据、profile 和运行设置。

#### Scenario: 候选包要求宿主不存在的导出
- **WHEN** 替代界面使用宿主导出表不存在的 useAnchoredPosition
- **THEN** 工具报告相对包 ID 和缺失导出，并以非零状态退出

#### Scenario: 候选包只使用存在的具名导出
- **WHEN** 四个替代界面全部具名原语引用存在于指定宿主的唯一导出表
- **THEN** 检查通过，同时提示仍需真实 Desktop 验收

### Requirement: 不以未知结构或空扫描冒充通过
工具 MUST 拒绝无法解析、缺失、重复或不支持的导出结构、动态原语属性访问及没有发现任何原语引用的扫描，不执行被检查脚本。

#### Scenario: 宿主构建结构变化
- **WHEN** 指定前端中无法识别唯一的原语注入导出表
- **THEN** 检查失败，不报告兼容

#### Scenario: 原语访问不能静态判定
- **WHEN** 插件通过动态键访问原语或扫描没有发现原语引用
- **THEN** 检查失败，保留真实验收要求

#### Scenario: 输入含顶层执行语句
- **WHEN** 被检查脚本包含顶层抛错语句
- **THEN** 工具只解析源码，语句不会被执行
