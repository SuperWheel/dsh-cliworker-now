## Context

runtime manifest 保证分发文件完整性，不能保证宿主前端注入的原语包含替代界面需要的每个导出。故障发生在浏览器层，不能仅依靠 Host 模块来源和 Loader 验证。

## Goals / Non-Goals

目标：无需执行外部代码即可识别缺失的具名原语导出；对候选解包目录和指定宿主前端可重复运行；公开结果不包含个人资料。

范围外：运行时接口降级、自动探测用户安装、函数类型及行为兼容、其他模块检查、发布或模型任务。

## Decisions

使用已有 TypeScript 开发依赖解析 AST，识别宿主模块种子中的原语导出表，以及插件 CommonJS factory 内的 namespace、静态属性、具名解构和直接 require 引用。支持 Object.freeze / Object.defineProperty 包装和压缩标识符变更。遇到不支持结构或动态访问时拒绝通过。

运行前保留现有 verifyHostRuntime 检查，不能用任意修改过的 runtime 绕过完整性清单。工具为显式开发入口，不注入生产加载过程，也不修改已运行的 Desktop。

## Risks / Trade-offs

静态具名检查无法证明签名、行为、别的浏览器模块或整套产品兼容；工具及文档明确说明仍需真实 Desktop 验收。宿主构建结构变化可能需要更新解析器，未知结构必须失败。错误输出使用包 ID 和导出名，不收集用户日志；文件访问异常只报告错误代码。

## Migration Plan

无用户数据迁移。检查代码可直接撤销，不影响已有安装；未触碰生产插件和版本号。
