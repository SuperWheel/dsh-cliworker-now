# Proposal

## Why

用户对最新设置截图明确要求：模型与思考强度选择后自动保存；高级设置只保留右侧箭头按钮效果；路径管理使用普通标签格式，并删除重复路径标签和来源文字。当前 settings-dialog 仍依赖提交按钮，路径子组件把整行标题作按钮，需按实际交互调整。

## What Changes

- 移除项目默认设置保存按钮，用户选择原生模型/强度后保存，初始读取和刷新不自动写偏好；保存失败可见，连续选择以最新值为准。
- 模型/思考强度的下拉菜单与选择框等宽对齐；移除思考强度与高级设置之间重复的行底边。
- 高级设置保持独立、默认折叠；静态标题配右侧小箭头按钮，保留折叠过渡并照顾减少动态效果。
- CLI 路径管理采用模型/思考强度标签样式；删除重复可见的 CLI 路径及来源文字，保留输入可访问名称、说明、恢复自动识别与刷新。
- 以现有账号、项目默认设置的文字层级和模型行 16px 留白为基准，统一三块设置的排版变量、内容行、分隔线与反馈间距；形成可复用的设置页设计规范，后续扩展复用同一规则。

## Capabilities

### New Capabilities
无。

### Modified Capabilities
- `worker-management`：项目 CLI 模型偏好的用户选择自动保存。
- `harness-cli-path-settings`：高级设置与路径管理的简化交互和文字层级。

## Impact

只调整 React Client 与相关 UI 测试，复用现有 Gateway configure 和路径 API，不更改 CLI/账号/模型权限。同步 README、设计、实际最小验收及规格；先 preview，再无活动任务时更新 Mac/Windows 本地 v0.7.8。无版本增加、GitHub 推送、全量验收或真实模型任务。
