# Spec Delta

## ADDED Requirements

### Requirement: 项目 CLI 默认模型自动保存
Client SHALL 在用户选择有效模型或思考强度后自动保存当前项目及 CLI 的完整偏好组合，不要求点击保存按钮。初始化与刷新模型目录 MUST 只读取、不写入偏好；只有模型真实声明的强度可被保存。模型与思考强度下拉菜单 SHALL 与各自选择框等宽，并保持左右边缘对齐。

#### Scenario: 选择后自动保存
- **WHEN** 用户选择有效模型或思考强度
- **THEN** 自动保存当前组合并反馈结果；新模型不支持旧强度时采用该模型已声明的有效选项，不发送不兼容组合

#### Scenario: 初始读取
- **WHEN** 用户打开设置、切换 CLI 或刷新模型列表
- **THEN** 显示已保存或可选候选，不自动调用保存，不以默认展示当作用户选择

#### Scenario: 连续选择
- **WHEN** 前一次保存尚未结束而用户继续选择
- **THEN** 最终保存最新组合，不并发乱序写入，旧成功或错误不能覆盖最新反馈

#### Scenario: 保存失败与页面离开
- **WHEN** 保存失败或页面关闭、切换 CLI、账号范围改变
- **THEN** 失败明确提示并保留当前选择供重试；离开或范围改变取消旧保存和待保存值，不把迟到结果应用到新页面

#### Scenario: 下拉菜单宽度
- **WHEN** 用户打开模型或思考强度菜单
- **THEN** 菜单宽度跟随对应选择框，不因列表内容长短变宽，左右边缘与选择框对齐
