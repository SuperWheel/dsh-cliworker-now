# Spec Delta

## MODIFIED Requirements

### Requirement: 独立且默认折叠的高级设置
每个 CLI 设置页 SHALL 在“项目默认设置”之外设置同级“高级设置”大标题，默认折叠。与项目默认设置之间 SHALL 只保留一条分区线，不叠加末行底边。标题 MUST 为静态文本，仅右侧箭头按钮提供点击与按钮效果，展开/折叠保留过渡并遵循减少动态效果偏好。“CLI 路径管理” SHALL 位于展开后的高级设置中，使用与模型/思考强度一致的普通标签格式，自动预填已发现路径；未发现时留空。不得重复显示输入框前的“CLI 路径”标签或底部路径来源文字，但输入 MUST 保留可访问名称。允许用户输入完整文件路径并点击“刷新”，校验、保存并更新 CLI 状态。路径设置 SHALL 为本机跨项目共享，不归入项目模型和思考强度设置。

#### Scenario: 页面初始状态
- **WHEN** 首次打开或切换 CLI 设置页
- **THEN** 高级设置保持折叠，展开后显示当前 CLI 自身路径，不显示其他 CLI 或其他平台的保存路径

#### Scenario: 右侧箭头与文字层级
- **WHEN** 用户操作高级设置
- **THEN** 仅右侧箭头为按钮，标题不是整行按钮；路径管理标签与上方普通设置标签一致，保留说明、恢复自动识别和刷新，无重复可见路径/来源标签

#### Scenario: 统一设置页排版
- **WHEN** 展开高级设置或新增设置内容
- **THEN** 分区标题、普通标签和说明各自沿用账号与项目默认设置对应文字层级，内容行使用与模型行一致的上下留白；标题到内容及文字到分隔线的距离使用统一设计规范，不叠加分区外距，空反馈不额外占位

#### Scenario: 手动刷新
- **WHEN** 用户输入绝对 CLI 路径并点击刷新
- **THEN** 保存手动来源并重新校验账号/模型状态，校验失败保留输入且展示错误，不显示旧的成功状态

#### Scenario: 恢复自动识别
- **WHEN** 用户点击恢复自动识别
- **THEN** 清除 UI 手动来源及定位缓存并重新发现；部署显式配置仍保留，失败时明确提示未找到
