# Design

## Context

settings-dialog.tsx 目前在表单提交后调用 configure；初始化模型目录可预填候选但不得视为用户授权选择。路径组件已有独立高级 section，需要调整点击区域、动效和文本。

## Goals / Non-Goals

Goals：实现事件驱动自动保存、最新选择一致性、清晰保存反馈、精简路径区域并保持可访问操作。
Non-Goals：不改 Host 保存协议、账号来源、CLI 路径持久化、默认模型能力或用户的模型授权范围。

## Decisions

- 仅选择事件发起自动保存。模型变更时先核验其原生强度集合，不兼容的旧强度换为该模型已声明的首选项，再保存完整组合；首读/重新取目录只展示。
- 保存请求串行，连续选择合并最新待保存值并取消旧请求，旧响应不能回写新显示；关闭/切 CLI/账号改变清理队列。保存失败保留选择并显示错误，同值重选允许重试；不保留提交按钮或 Enter 隐式保存。
- 模型/强度菜单沿用宿主 Menu portal/start 定位；宿主没有 match-width API，以按钮 ref/ResizeObserver 跟踪实际宽度，通过实例 CSS 变量传给列表，不重写定位；关闭/卸载清理 observer。思考强度作为最后一行移除底边，仅保留高级设置分区线。
- 高级标题为静态 h3，右侧原生小按钮控制 aria-expanded。折叠使用现有 settings CLI 导航的 CSS grid/opacity 过渡模式，收起时输入不可交互并取消查询，减少动态效果偏好下不播放。
- 路径管理为普通 label，样式复用现有设置行标题；辅助说明保留。删除重复可见 label/来源，仅保留可访问输入名，不影响真实路径来源存储。
- 将字号、行高、字重、16px 内容行留白、8px 标题后间距、4px 说明间距、分隔线和控件尺寸集中为设置布局变量。高级路径区域复用同一内容行间距；相邻分区不叠加 margin 与上一行 padding。反馈按实际内容参与布局，空反馈不占位。`doc/settings-ui-design.md` 记录参数、组件组合和后续扩展规则。

## Risks / Trade-offs

- 自动保存会在用户明确选择后即写项目偏好；纯读取不能写。保存中切换需等待旧请求清理后提交新值，不能并发写出乱序。
- 真实 UI 最小验收使用现有默认组合的明确重选，核对保存反馈与重开一致；不启动模型，不改变账号。

## Migration Plan

无数据迁移；偏好与路径均保留现有格式。回退 Client 即恢复旧提交交互。版本仍 v0.7.8。
