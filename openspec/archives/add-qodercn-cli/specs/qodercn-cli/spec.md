# Spec Delta

## Purpose

为 Qoder 中国版提供独立、可核验的 CLI 选型、账号、动态模型及原生会话入口。在中国版与国际版并存时保持来源、偏好、执行、清理保护和遥测隔离，并明确未完成的真实平台和模型验收。

## ADDED Requirements

### Requirement: 独立中国版身份
插件 SHALL 将 `qodercn` 与 `qoder` 作为两个不同 CLI，分别管理项目偏好、路径、目录缓存、清理保护和原生会话协议，MUST 不把中国版当国际版别名或迁移旧会话。

#### Scenario: 明确指定版本
- **WHEN** 用户明确选择 qodercn、中国版或 qoder 国际版
- **THEN** 仅使用该版本的入口与项目偏好，不回退另一版本；中国版新会话绑定 `qodercn-acp-v1`，国际版历史保持原身份。

#### Scenario: 泛称 Qoder 且仅一版安装
- **WHEN** 用户泛称调用 qoder，且只检测到 qoder 或只检测到 qodercn
- **THEN** 自动路由到唯一已安装版本；安装检测不读取凭据或发起模型请求。

#### Scenario: 泛称 Qoder 且两版同时安装
- **WHEN** 用户泛称调用 qoder，且两版都已安装
- **THEN** 在宿主原生询问框中提供 Qoder 与 Qoder CN 选项，等待用户选择后再进入模型选型；取消或无有效选择不得启动。

#### Scenario: 安装未知或两版均缺失
- **WHEN** 安装探测错误、未确认，或两版均不存在
- **THEN** 保留明确的不可用或未知状态，不把错误当作未安装从而静默改版。


#### Scenario: 跨版程序或协议
- **WHEN** 自动发现的入口、原生初始化身份或恢复协议属于另一版本
- **THEN** 拒绝任务并保留原记录，不尝试另一版入口或新建替代会话。

### Requirement: 自身账号与动态模型
中国版 SHALL 只读取自身配置目录和认证来源，模型及强度 MUST 来自当前原生结构化目录，不复制国际版档位、不回退另一版 PAT。账号和目录查询必须无 prompt、有界、只读并确认结束与进程范围退出。

#### Scenario: 独立环境与共享 SDK 控制变量
- **WHEN** Host 环境同时存在 QODER 与 QODERCN 变量
- **THEN** 选中版本只使用自身配置和 PAT，清除对侧运行控制变量；共享 SDK 控制变量仅用于本次私有元数据进程。

#### Scenario: 缺少登录或目录
- **WHEN** 中国版未登录、原生来源改变、配置含未绑定路由或目录无法确认
- **THEN** 明确报告中国版不可用并拒绝发送任务，不借用国际版登录、默认模型或已缓存选型。

#### Scenario: 查询失败或取消
- **WHEN** 查询被取消、返回无效数据或进程范围退出未确认
- **THEN** 不发布成功目录，按中国版归属保留清理失败，不修改其他 CLI 账号与已有会话。

### Requirement: 中国版原生会话与权限
中国版 SHALL 使用自身 ACP 初始化、动态选型与真实会话 ID；续聊 MUST 验证自身协议及账号，拒绝未确认的模型、额外权限和不支持的规划模式。停止仅在进程范围退出后成功，公开过程不得伪造。

#### Scenario: 新建和恢复
- **WHEN** 中国版新建或续聊任务
- **THEN** 在原生身份、会话、模型及权限回执确认后发送 prompt，忽略恢复重放，不跨版恢复。

#### Scenario: 额外权限与停止
- **WHEN** 原生请求未授权权限或用户停止
- **THEN** 额外权限被拒绝，停止等待本次完整进程范围退出；缺少工具终态或清理未确认不得报告成功。

### Requirement: 独立遥测和验证证据
中国版 SHALL 在既有布局显示其自身公开事件、积分和上下文，MUST 核对 CLI、会话、轮次与模型来源；缺失计数保持未知，隐藏零不冒充真实零。文档必须区分模拟、真实元数据、Desktop 与模型验收。

#### Scenario: 两版同名会话或模型
- **WHEN** 遥测来源属于另一版本或同名会话存在于另一配置根
- **THEN** 不接受对侧数据，不从另一版补读积分、上下文或日志。

#### Scenario: 未登录的实机
- **WHEN** 实机仅完成入口、帮助、初始化或未登录检查
- **THEN** 记录对应证据，不声称真实生成、续聊、工具或取消已经通过。
