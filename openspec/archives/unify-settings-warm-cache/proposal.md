# Proposal

## Why

现有设置页仅在当前打开期间缓存账号，模型仅按所选 CLI 加载。关闭后重新查询账号，Windows 原生进程开销放大了等待；Mac 实现也存在同样缺口。

## What Changes

- macOS 与 Windows 复用同一套展示缓存，首次打开有界预加载所有已启用 CLI 的登录摘要、模型及思考强度。
- 完成的展示结果按当前 Gateway、Host 实例及项目保留；关闭取消未完成工作，重开只补缺项。
- 用轻量设置元数据核对宿主代际、CLI 来源版本、开关和项目默认值；登录、路径及开关变化使对应缓存失效，显式刷新仍执行新查询。
- 展示缓存不参与保存选型或执行授权，不持久保存账号摘要或凭据；不新增生成调用。运行验收仅 Windows，Mac 核对源码与已安装实现。
- 按补充要求，模型与思考强度选择仅更新草稿；离开当前 CLI 页面或关闭设置时后台保存最终组合，写入不中断导航，关闭后仍完成，失败可在重开时查看和重试。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `cli-model-discovery`：首次设置预热、重复打开复用、失效与生命周期。
- `worker-management`：项目默认模型与强度的离页后台保存及关闭生命周期。

## Impact

Client 设置页和展示缓存、Host 轻量设置元数据、相关测试及文档。保留现有模型持久目录、Gateway 签名、UI 样式和执行重检，不增加版本号、依赖或系统专用缓存分支。
