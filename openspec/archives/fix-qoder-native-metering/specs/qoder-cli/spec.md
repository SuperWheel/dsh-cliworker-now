# Spec Delta

## MODIFIED Requirements

### Requirement: 原生统计及明确未知
Qoder 子会话 SHALL 在原生轮次、用量和上下文组件中展示有证据的数据，并保留原生详情交互。用量、积分与上下文 MUST 绑定当前 Worker、CLI 会话、轮次和模型，区分消耗和当前窗口；隐藏 token 不得显示为真实零。原生比例可独立展示；仅在实际窗口有同轮原生证据时计算占用估算并标注来源，不使用默认容量。macOS 与 Windows 均使用有界只读采集，缺失字段保持未知。

#### Scenario: 原生统计已提供
- **WHEN** Qoder 协议或身份核对通过的只读持久记录提供用量或当前窗口信息
- **THEN** 通过现有会话投影展示相应值和来源，重复读取不重复累加，分类、缓存和容量缺失时明确未知。

#### Scenario: 没有统计或旧轮缺失
- **WHEN** Qoder 没有提供某项统计，或旧轮次未采集且无可核对来源
- **THEN** 组件展示可查看的未知说明，不从别的会话取值，不以默认零代替缺失，不改写旧事件。

#### Scenario: 停止或身份不符
- **WHEN** 任务中断、持久文件不安全、记录超限或返回不匹配会话及模型
- **THEN** 丢弃不可信更新，保留已核实数据及未知边界，不影响停止清理和任务终态判定。

#### Scenario: 积分存在但 token 未公开
- **WHEN** 本轮原生请求提供有效 Credits，而 token 桶均为隐藏零或缺失
- **THEN** 原生用量入口和详情显示本轮积分并明确 token 未公开，不从积分或上下文反推账单 token；多段同请求记录仅计算一次，明确零积分可显示。

#### Scenario: ACP 扩展回执补充计数
- **WHEN** 主回执缺少或隐藏计数，扩展 quota 提供可核对且总和一致的非零输入输出
- **THEN** 展示扩展回执的真实计数，矛盾或不完整数据保持未知，不把不同来源的桶拼成虚假总量。

#### Scenario: 实际上下文窗口可核对
- **WHEN** 同轮原生记录或同会话同轮日志提供有效容量，且终态记录提供有效比例
- **THEN** 展示比例、容量和明确标为估算的已用量；日志缺失、迟到、跨轮或不匹配时继续显示已有比例和积分。

#### Scenario: 跨平台私有来源读取
- **WHEN** macOS 或 Windows 读取包含中文、空格、盘符或长路径的 Qoder 原生项目记录
- **THEN** 按官方项目目录算法定位同一来源；Windows 异步验证当前用户所有权，或 Administrators 所有权加当前用户直接完全控制，允许原生继承只读权限并拒绝不可信写权限；读取失败或取消不阻塞任务清理，缓存仅保留数字及来源指纹，原生 ACL 不被修改。
