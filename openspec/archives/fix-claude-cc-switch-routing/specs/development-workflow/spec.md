# Spec Delta

## ADDED Requirements

### Requirement: 日常最小验收与版本冻结
日常修复和调整 SHALL 仅执行与影响范围对应的最小验收；全量验收 SHALL 在用户批准的版本发布流程执行。当前开发版本 MUST 保持 v0.7.8，只有用户明确批准才增加版本号或提交 GitHub；未批准且未上传 GitHub 的改动仍属于该版本下调整。最小验收 SHALL 明确已执行检查和未验证边界。

#### Scenario: 当前版本内修复
- **WHEN** 用户要求修复 Claude 路由兼容性但未批准新版本发布
- **THEN** 保持开发版本 v0.7.8，执行关联检查、隔离构建及必要最小平台验证，不执行全量 CLI 验收、不推送或发布

#### Scenario: 版本发布
- **WHEN** 用户明确批准增加版本号和发布
- **THEN** 按发布范围执行全量验收并核对安装及分发证据，未验证项继续保留
