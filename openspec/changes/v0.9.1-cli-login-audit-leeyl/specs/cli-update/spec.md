## ADDED Requirements

### Requirement: CLI 版本变化后重读账号状态
某个 CLI 经「更新 CLI」页更新或安装完成，或 Host 发现其版本指纹（真实路径、文件大小、修改时间，桌面应用再加应用包版本号）变化时，Host SHALL 作废该 CLI 的账号登录状态缓存与模型目录显示缓存，下次显示设置页或派遣前 SHALL 按新版重读，MUST NOT 继续显示更新前的登录结果。其他 CLI 的缓存不受影响。

#### Scenario: 更新后登录存放位置改变
- **WHEN** 用户在「更新 CLI」页把某个 CLI 更新到新版本，新版本改变了登录的存放位置
- **THEN** 设置页不再显示更新前缓存的登录状态，改为按新版重读后的结果

#### Scenario: CLI 自行更新
- **WHEN** CLI 在插件之外自行升级，Host 下次读取时发现版本指纹变化
- **THEN** 该 CLI 的账号与模型显示缓存作废并重读，其他 CLI 的缓存保留
