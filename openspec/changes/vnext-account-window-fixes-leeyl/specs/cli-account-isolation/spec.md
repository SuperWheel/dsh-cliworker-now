## ADDED Requirements

### Requirement: 账号终端启动前等待同一 CLI 的读取收尾
Host SHALL 在启动某 CLI 的账号终端前，等待该 CLI 已取消的账号查询与模型目录读取通道的进程范围全部退出，并复查清理隔离状态；终端占用期间 MUST NOT 启动该 CLI 新的展示查询或模型目录读取，终端清理成功后才恢复，清理未确认时保持拦截。

#### Scenario: 模型目录读取仍在进行时打开登录终端
- **WHEN** 用户在账号窗口选择服务商登录，而同一 CLI 的模型目录读取尚未结束
- **THEN** Host 先取消并等待该读取退出，再准备并启动账号终端，不因进程冲突启动失败

### Requirement: 登录结束后账号窗口立即显示新凭据
Host SHALL 在终端启动前读取登录基线，并在进程清理、运行目录释放与账号缓存作废之后才发布成功状态；Client SHALL 在登录结束、返回列表或保存服务商后，为打开中的账号窗口直接读取带操作句柄的新状态，迟到的旧窗口读取 MUST 被丢弃。

#### Scenario: 快速完成登录
- **WHEN** 用户在 OMP、Pi、OpenCode、Kimi、Hermes 或 ZCode 的账号窗口完成登录并返回列表
- **THEN** 列表与连接页摘要立即包含新凭据，不需要等待后台刷新

### Requirement: 原生模型配置文件中的服务商可删除
Pi 与 OMP 原生模型配置文件中的服务商 SHALL 在账号窗口提供「删除」，经内联确认后只移除该服务商；删除前 MUST 备份原文件到插件状态目录（0600），以原子替换保留其余内容、格式与文件权限，拒绝链接与无法安全编辑的结构，失败回滚，独立回读确认后才报成功。插件表单写入的服务商凭归属回执同样可删除；环境变量来源 SHALL 保持只读。

#### Scenario: 删除用户手写的 OMP 服务商
- **WHEN** 用户对「其他配置」中来自 `~/.omp/agent/models.yml` 的服务商点击「删除」并确认
- **THEN** 原文件先备份，仅该服务商从原生文件与一致的插件快照中移除，列表刷新后不再出现

#### Scenario: 环境变量来源
- **WHEN** 服务商仅来自环境变量
- **THEN** 账号窗口显示「在原配置中管理」，不提供删除

### Requirement: Pi 定向退出只核对所选来源
Pi 退出 SHALL 只读取并修改所选来源的 auth.json，以 Pi 原生 AuthStorage 删除该服务商并用新的存储实例回读确认；其他来源或无关模型配置的解析失败 MUST NOT 使退出判定为未确认。Pi 登录准备 SHALL 不依赖完整模型配置解析即可列出服务商。

#### Scenario: 无关模型配置损坏
- **WHEN** 另一来源的模型配置无法解析，用户退出所选 Pi 凭据
- **THEN** 退出在原生记录移除且进程清理完成后报告成功
