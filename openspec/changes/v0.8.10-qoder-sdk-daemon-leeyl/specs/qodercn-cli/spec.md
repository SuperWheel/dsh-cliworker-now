## ADDED Requirements

### Requirement: 元数据协议版本兼容
Qoder CN 元数据查询 SHALL 根据所选入口的可靠版本证据选择协议：高于 1.1.80 使用私有 SDK daemon，较旧版本使用 worker。无版本证据时 MUST 有界探测；仅明确协议不支持可切换一次，两次都不得发送 prompt、建立模型会话或复用全局 daemon。认证、网络、超时、取消和清理失败不得触发切换。

#### Scenario: 新版账号与模型
- **WHEN** 所选 CLI 使用 daemon 元数据协议
- **THEN** 校验握手版本与账号查询能力，取得自身账号与完整动态模型（保留自定义模型、过滤停用模型、保留明确强度），确认 shutdown 回执和进程范围退出后发布结果；所有可写状态与一次性认证文件隔离到本次私有目录。

#### Scenario: 旧版或未知版本
- **WHEN** 入口为旧版或无法取得可靠版本，原生明确拒绝所选协议
- **THEN** 旧版默认使用原 worker 路径；协议切换最多一次，前次范围退出与私有目录清理确认后才可启动后次；仍失败时保留脱敏的协议不兼容原因。

#### Scenario: 元数据失败与中断
- **WHEN** 握手、查询、结束回执失败，输出超限、超时、用户取消或进程提前退出
- **THEN** 不发布账号或模型成功，终止并等待本次进程范围退出；未确认退出保留清理失败，不删除仍被进程使用的临时目录，不改用户配置与其他会话，不输出凭据。
