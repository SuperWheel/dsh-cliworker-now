| 项目 | 内容 |

| 备选标题 | ① 智商高的干活，便宜的指挥：DSH × CLI Worker 让 Codex 打工 ② 蓝色大肥鱼抽了 Codex 一鞭子，还用 QQ 给我发了表情包 |

> 角色约定：**蓝色大肥鱼 = DeepSeek = DSH 主 Agent**；**梗图里被鞭子抽的白发角色 = Codex = CLI Worker**；**主人 = 你**。

## 0. 录制前准备

1. **DSH Desktop** + **CLI Worker v0.8.7**；主 Agent 模型选 DeepSeek，右侧栏打开 CLI Worker。
2. **Codex CLI** 已登录，账号能用 `gpt-6.1-sol` 和 image gen；本机有 Python Pillow 或 ffmpeg，用来把帧合成 GIF。Codex Computer Use 已获得 macOS 辅助功能和屏幕录制权限。
3. **QQ 准备两个号**：Mac 上的 QQ 登录「蓝色大肥鱼」小号（头像换成蓝色大肥鱼），好友备注为「主人」的是你的大号；大号登录在手机上，用来拍收到表情包的画面。QQ 窗口只保留和「主人」的对话，录屏前关掉其他会话、群和通知，避免录到个人信息。
4. 新建演示项目 `~/demo/fish-boss`，把 [人设图](assets/blue-fish-character.png) 复制到 `assets/ref/blue-fish-character.png`。
5. Codex Worker 档位选「自动审批」。Computer Use 请求操作 QQ 时，主对话会弹出授权卡片，这一幕是笑点之一，要拍到。
6. **梗图素材**：两张梗图（Codex 抽 DeepSeek 的原版、DeepSeek 抽 Codex 的反转版）来自网络，发布前确认作者或来源允许二次创作，并在简介注明出处；无法确认时用 Codex 生成的表情包替代开场画面。
7. **必须先彩排**：image gen 生成连贯动作帧、合成 GIF、Computer Use 操作 QQ 发送，这三步都没有在本插件里做过真实验收（见第 9 节）。先私下跑通，再正式录。
8. 音效：鞭子「啪」、翻转「嗖」、QQ 消息提示音（用 QQ 自带的即可）。配乐选轻快但不吵的电子或 Lo-fi，旁白时压低到 -18 dB 左右。

## 8. 哈基米配音建议

- **音色来源**：在剪映、魔音工坊等配音平台搜「哈基米」「猫猫」类音色，选平台标明可商用或可用于发布视频的音色；不要直接剪别人视频里的原声，也不要克隆具体主播或声优的声音。
- **语速**：哈基米音色本身拖音多，建议 1.0～1.1 倍；「本鱼不服。今天，倒反天罡。」「codex-1，上岗！」「主人，请查收。」这类梗句单独生成，前后各留 0.3 秒停顿。
- **英文和缩写**：Codex、Claude Code、GPT 等词 TTS 可能读得怪，生成后逐句试听；读错的就在旁白里改成拼读写法（例如「G P T 六点一 sol」），字幕保持原写法。
- **点缀**：开头「哈基米～本鱼听说」和结尾「哈基米～」是全片仅有的两处口癖，保持克制，中间不要再加，避免观众听腻。
- **字幕**：单行短句，跟旁白逐句对齐；梗字幕（「老板只动嘴」「老板也得请示主人」）字号略大、停留 1.5 秒。
